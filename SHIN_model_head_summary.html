SHIN 各模型分类头总结

本文按本地代码与各项目官方下游实现整理 CodeBrain、LaBraM、CBraMod、 官方 CSBrain、EEGNet、fNIRS-Transformer 与 DAMFNet 的分类头。

范围：当前正式采用并纳入结果比较的模型版本

核心结论

已对齐官方实现

七个模型均采用各自官方库给出的下游分类头，只把最终类别数适配为 SHIN 二分类。

结构不强行统一

各官方模型采用不同的聚合方式、隐藏层和正则化；保留差异才能维持官方模型定义。

未启用通用兜底头

所有官方库均提供分类头，因此没有模型使用“展平 → LayerNorm → 自定义三层 MLP”。

DAMFNet 三个头如何共同训练

训练阶段（官方多头监督）

EEG logits ─┐
HbR logits ─┼─ 三个交叉熵相加并反向传播
融合 logits ─┘

L = L_EEG + L_HbR + L_fusion

验证和测试阶段

EEG + HbR → 融合网络 → 融合主头 → 最终类别

两个辅助头用于训练约束，不与融合头投票；滑动窗口实验再对同一 trial 的窗口 logits 求平均。

DAMFNet 的通道方案从“全部通道学习投影”改为固定 8 个 EEG / 24 个 fNIRS 通道， 以及后续调整时间窗、早停轮数，都没有改变上述三个分类头。

官方对齐后的比较边界

  • 可以统一描述的部分：全部是二分类，最终输出均为 [B,2] logits，训练目标为交叉熵。
  • 官方结构不统一：特征聚合方式、输入维度、分类头层数、激活函数、Dropout 和权重约束均由各官方项目决定。
  • 当前比较的正确名称：“各模型官方分类头结果”，不是严格的统一 linear probe。
  • 参数量风险：CodeBrain、CBraMod 和官方 CSBrain 的 SHIN 三层头均约有 1.204 亿参数；FP32 AdamW 仅分类头的权重、梯度和两组动量约占 1.79 GiB，还不含骨干与激活。
  • 不建议给 LaBraM 使用全 token 展平 MLP：官方已经通过 mean pooling 得到稳定的 200 维表示；全展平会绑定 token 数并大幅增加过拟合风险。
  • 不建议给 EEGNet 使用通用三层 MLP：它的紧凑线性层和 max-norm 约束是官方 EEGNet 正则化设计的一部分。
  • 不建议给 fNIRS-Transformer 使用全 token 展平：两个 Transformer 的 CLS/mean 表示已经完成聚合，展平所有 token 会令分类头依赖输入长度。
  • DAMFNet 不应替换为单一通用头：EEG、HbR 辅助监督和融合主头共同构成官方多模态训练目标。
